# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides computing, storage, networking, databases, artificial intelligence, machine learning, analytics, and application development services.

## Global Infrastructure

Google Cloud currently operates across 43 global regions and 130 zones. Its infrastructure is distributed across six continents and is designed to provide scalability, low latency, and high availability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services

1. Compute Engine – Provides virtual machines.
2. Cloud Storage – Provides object storage.
3. Virtual Private Cloud (VPC) – Provides cloud networking.
4. Google Kubernetes Engine (GKE) – Provides managed Kubernetes clusters.

## Three Advantages

1. Strong capabilities in artificial intelligence and machine learning.
2. Strong Kubernetes and container-management capabilities.
3. Google's global network provides high-performance connectivity.

## Typical Enterprise Use Cases

Google Cloud is commonly used for artificial intelligence and machine learning, data analytics, Kubernetes applications, web applications, data storage, and large-scale cloud workloads.
