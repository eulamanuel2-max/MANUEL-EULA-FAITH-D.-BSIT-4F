# Mission 5: The Cloud Data Engineer

## Mission Overview

This mission demonstrates how object storage can be used for a photo-sharing application that needs to store millions of user-uploaded images. The task is to deploy an S3-compatible object storage server using MinIO and Docker, access its web console, create a bucket, and upload a test file.

## Objectives

- Differentiate Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console through port 9001.
- Create a private bucket named `client-photos`.
- Upload a test image or text file.
- Document the deployment using Markdown.
