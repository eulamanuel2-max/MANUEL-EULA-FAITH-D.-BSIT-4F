## Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is widely recognized for having a very broad portfolio of cloud services. Its services cover areas such as computing, storage, networking, databases, security, analytics, and artificial intelligence.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations that already depend heavily on Microsoft technologies. Azure works closely with products and technologies such as Windows Server, Microsoft 365, and Microsoft identity services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes workloads. Google Cloud provides AI and ML services as well as Google Kubernetes Engine (GKE), a managed Kubernetes service.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad selection of cloud services and can support many different types of workloads. Its range of services would give me flexibility when building and scaling applications.
